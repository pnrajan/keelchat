Describe a chatbot. Chat with it. Run it yourself.

In keelchat, a bot is one short YAML file: what it is for, what it asks, its rules and limits, and when it hands over to a person. Say what yours should do in a sentence or two; a model writes the file and keelchat checks that it builds.

Press Try this bot to talk to it here, ask for changes in plain words, then clone the repo and run it on your own machine. It's open source (Apache-2.0).

Chat with a ready-made support bot

It helps with a problem order: asks your consent, takes your order number and what went wrong, answers questions about returns, and passes you to a person if you ask. See its YAML.

Order details are sample data, so any order number works (try ORD-12345). Nothing you type is kept.

Replies come from a model and can be wrong. Nothing is saved.
