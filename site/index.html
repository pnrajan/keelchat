How it works

From a sentence to a running bot in minutes.

No prompt engineering. You say what the bot is for; keelchat writes a file you can read, and the runtime does exactly what the file says.

Describe it

"Book dental appointments; hand emergencies to a person." A model writes the YAML and the build checks it.

Try it, change it

Chat with your bot in the browser. Ask for changes in plain words: "also ask for an email".

Run it yourself

Clone the repo, run ./setup.sh, and serve it on your site, WhatsApp, SMS, Slack or the phone.

Why keelchat

A prompt works in a demo. Production needs rules.

When a bot has a job to finish, a prompt-only bot is asked to remember the steps, count its own attempts and know when to stop. It does, most of the time. keelchat moves those decisions into code and leaves the model to read and phrase.

Steps are code.A form isn't done until every field passes its check.

For developers

YAML says what it does. Python adds what it can reach.

Tools, steps, guardrails and channels plug into one registry, so a new tool shows up in the schema, the console and the tests without wiring.

my_caps/tools.py
from keelchat import tool

@tool("slot_search", timeout_s=3.0, retries=1)
async def slot_search(service: str, day: str = "") -> dict[str, list[str]]:
    """Open appointment slots for a service, optionally on one day."""
    return {"slots": await my_booking_api.free_slots(service, day)}

Type hints become the schema; the docstring is what the model reads. Allow it with tools: [slot_search].

Who it's for

One file the whole team can read.

Support and ops teams

Describe the bot in plain English, read back what it will do, ask for changes the same way. No YAML needed.

Developers

Add a tool, step, guardrail or channel as one decorated Python function, or connect an MCP server. Run many bots on one runtime.

Reviewers

Read one file per bot, see why each reply was chosen, and check the audit log, outcomes and model cost.

Not the right tool for a free-form assistant, multi-agent research workflows, or if you need stable APIs today: keelchat is alpha. How it compares with Parlant, Rasa, LangGraph and Botpress.

Get started

Run it on your machine in three commands.

Needs macOS, Linux or WSL and one model key; setup.sh installs the rest. Or run it all in Docker with scripts/local.sh up.
